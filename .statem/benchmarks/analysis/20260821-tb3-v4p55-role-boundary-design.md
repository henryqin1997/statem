# TB3 v4p55 Solver, Reviewer, And Gate Boundary

## Motivation

The v4p54 MVCC matched cell preserved raw one and reached verified promotion,
but exposed two role-boundary defects:

1. solver obligations were complete ids and source bindings without compact
   executable semantics; and
2. a final reviewer produced semantically complete evidence that exceeded an
   unadvertised mechanical text bound, so the candidate lifecycle paid for a
   reviewer receipt-expression failure.

## Minimal Control

v4p55 does not disclose a reviewer answer key. Every solver-facing obligation
now carries three bounded fields:

- `invariant`: the public property that must remain true;
- `required_action`: what the implementer must do before proposal; and
- `self_check`: what candidate-bound public evidence it must produce.

Four shared practices provide explicit solver projections. Primary profile
checks project their bound reviewer-document guidance; long guidance projects
its first complete sentence plus an instruction to apply the complete bound
check. Secondary profiles remain compact scopes. Counterexample ordering,
adversarial probe selection, and verdict calibration remain reviewer-private
classes.

The final reviewer assignment now declares the exact 600-character bound for
`evidence`, `independence_basis`, and `unresolved_reason`. If an assessment is
still mechanically invalid, the fail-closed promotion receipt attributes it to
`reviewer_receipt_expression`, marks that candidate revision is not required,
and never truncates or rewrites semantic evidence. This attribution is not yet
a dedicated reviewer-resubmission state; matched evidence must determine
whether the advertised schema eliminates the false candidate revision before a
larger lifecycle change is justified.

## Authority

- Solver: artifact mutation, recoverable search, public probes, self-checks.
- Reviewer: read-only candidate-bound semantic adjudication.
- Intelligent configurator/orchestrator: advisory routing and scheduling only.
- Deterministic gate: sole state-transition, identity, receipt, and promotion
  authority.

A structured reviewer concern still blocks promotion. Budget degradation may
quarantine an exact candidate for evaluation, but cannot produce release
authorization.

Status: code-valid, runtime-unpromoted. Run one matched raw-positive sentinel
before any fresh score lane. Compare raw reward, protocol validity, route,
