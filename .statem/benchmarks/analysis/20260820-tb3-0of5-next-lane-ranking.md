# TB3 public 0/5 next-lane ranking

## Decision rule

The phase-one queue maximizes expected raw gain per API dollar and lane-hour,
subject to a likely StateM-owned failure and a public, independently replayable
discriminator. Low price alone is insufficient. Each candidate is classified as
workflow/control, base capability, hardware/resource, mixed, or unresolved.
Two hypothesis-scoped cells without a new discriminator, narrower owner,
artifact improvement, validation delta, or replayable stage milestone park the
task.

Task metadata below is limited to public category, tags, timeout, and resource
requirements. Development samples are never reused as final holdouts.

## Advancement

The next lane is selected from this ranking only after the active cell is
preserved and attributed. A direct half may run before StateM promotion because
it is control-independent. A StateM score half requires a valid matched direct
result and a non-regressing risk sentinel. Family promotion still requires a
fresh same-family sentinel and matched risk k5 evidence.
