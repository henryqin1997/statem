# Data And Database Review

- **`transaction_and_cutover_boundary`**: Identify transaction, snapshot, schema, and cutover boundaries.
- **`concurrency_and_mixed_versions`**: Exercise concurrent readers/writers, partial migration, retries, backfill,
  rollback, duplicate application, stale replicas, and mixed-version clients.
- **`schema_and_value_semantics`**: Check constraints, nullability, ordering, collation, time zones, identifiers,
  precision, and serialization round trips.
- **`conservation_and_reconciliation`**: Verify data conservation and reconciliation with counts, keys, and invariants,
  not only successful commands.
- **`availability_consistency_reversibility`**: Separate availability, consistency, and reversibility claims.
